# E报销助手_f24016137

网页端课程作业。先提供员工自助查询有效制度，再扩展为授权查询本人单据状态。制度由行政专员乔姐维护，业务事实由财务专员周敏核对。

所有制度、人员与单据均为虚构教学数据；网站采用关键词检索，不调用付费 AI 接口。适用于本机演示。

## 启动网站

需要 Python 3.12 或更新版本。在本项目目录打开终端：

```powershell
python -m pip install -r requirements.txt
python run.py
```

然后在浏览器访问 **http://127.0.0.1:5000**。本机已安装 Flask 时可直接双击项目中的 `启动网站.bat`，再打开上述地址。运行窗口应保持打开；按 Ctrl+C 停止服务。

## 演示账号

统一演示密码：`demo123`。登录页点击角色卡片即可填入账号与密码，再点击登录。

| 账号 | 姓名 | 角色 | 能做什么 |

员工和财务不能修改制度；员工和行政不能修改单据事实。未登录用户可以查公开演示制度，单据查询要求员工登录及明确授权。后台也验证角色、授权和单据归属。

## 两期功能

第一期：有效制度查询、常见问法、原文依据、版本和日期展示、乔姐的制度维护。未生效、失效及停用版本不出现在员工查询中；日期区间重复的启用版本不能保存。

第二期：本人查询授权、授权撤销、个人单据及详情、周敏核对、核对历史记录。状态为待核对、审批中、待付款、已付款、已退回；尚未核对的信息有明确提示。

关键词检索支持交通、打车、高铁、住宿、酒店、发票等常用问法。显示匹配的制度原文，不能替代人工解释复杂问题。没有有效依据时提示联系乔姐。

## 数据与重置

数据库保存在 `instance/demo.sqlite3`，本地会话签名密钥保存在 `instance/secret.key`，均被版本库忽略。普通启动不会覆盖已修改的演示数据。

仅在需要恢复初始教学数据时，停止网站后执行：

```powershell
python -m flask --app run reset-demo --yes
```

**此命令会清空当前教学修改和核对历史，恢复四个账号、六份制度与四笔单据。** 初始制度日期相对于重置当天生成，保证课堂展示时仍有有效、未生效和失效示例。重置后退出旧账号并重新登录。

## 验证

```powershell
python -m unittest discover -v
```

测试数据库位于 `instance/tests` 的临时目录，运行结束自动清理，不修改演示数据库。关键检查覆盖制度日期、角色限制、本人数据隔离、授权撤销、输入验证、CSRF 和持久化。

课堂流程见 [演示指南](docs/demo-guide.md)，验证情况见 [验证记录](docs/verification.md)。

## 项目结构

```text
app/                    网站后端、模板和样式
  auth.py               登录、权限与 CSRF 校验
  policies.py           有效制度查询和维护
  claims.py             查询授权、本人单据及财务核对
  schema.sql            数据库结构
  seed.py               教学数据
tests/                  权限及业务测试
docs/                   设计、实施计划、演示和验证说明
run.py                  本机启动入口
启动网站.bat            Windows 启动入口
requirements.txt        Python 依赖
```

登录使用 Flask 签名 Cookie；角色与授权每次从服务端数据库校验。网站默认仅监听本机，不是公网生产部署版本。日志中出现 Flask 开发服务提示属于本机演示的正常启动提示。
